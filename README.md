# Automation Playwright Portfolio
# QA Automation Portfolio

## Tech Stack
- Playwright
- TypeScript
- GitHub Actions
- ESLint
- Prettier

## Features
- Page Object Model
- Cross-browser testing
- CI execution
- HTML reports
- Reusable fixtures
- Environment configuration

## Test Scenarios
- Login
- Search
- Checkout
- Forms
- API validations

## Run locally
1. `npm ci`
2. `npx playwright install`
3. `npm test`
4. `npm run test:report` -> luego `npx playwright show-report`
